# Не забудь поздравить

Мобильный календарь-помощник для семьи: напоминает о днях рождения и праздниках Казахстана, при напоминании Claude предлагает подарки и поздравления. Пользователи — русскоязычная семья в Казахстане; весь текст интерфейса на русском, комментарии в коде тоже на русском.

## Структура

- `app/` — Expo SDK 58 + Expo Router (маршруты в `app/src/app/`).
  - `src/core/` — чистая логика без React Native: даты, поводы, план напоминаний. Всё новое в расчётах — сюда и с тестами в `core.test.ts`.
  - `src/data/holidaysKz.ts` — праздники РК.
  - `src/services/` — уведомления (expo-notifications), запрос идей к серверу.
  - `src/state/store.tsx` — данные в AsyncStorage, после изменений перепланирует уведомления.
  - `src/ui/` — общие компоненты и цвета (`kit.tsx`).
- `server/` — Node + Hono, вызывает Anthropic API. Контракт запроса — `server/src/schema.ts`, его зеркало — `app/src/services/ideasApi.ts`: меняйте оба.

## Команды

```bash
cd app && npm test && npm run typecheck
cd server && npm test && npm run typecheck
```

Перед изменениями в приложении: Expo часто меняет API — сверяйтесь с типами в `node_modules`, а не с памятью. Пакеты ставьте через `npx expo install`.

## Правила

- Ключ Anthropic только на сервере, никогда в приложении.
- Данные о людях хранятся на телефоне; на сервер уходит только то, что нужно для идей.
- Каждое изменение логики дат или напоминаний — с тестом.
