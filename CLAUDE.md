# Calendar

Простое мобильное приложение для семьи: напоминает о днях рождения и праздниках Казахстана. Работает офлайн, без сервера. Пользователи — русскоязычная семья в Казахстане; весь текст интерфейса на русском, комментарии в коде тоже на русском.

## Структура

- `app/` — Expo SDK 58 + Expo Router (маршруты в `app/src/app/`).
  - `src/core/` — чистая логика без React Native: даты, поводы, план напоминаний. Всё новое в расчётах — сюда и с тестами в `core.test.ts`.
  - `src/data/holidaysKz.ts` — праздники РК.
  - `src/services/notifications.ts` — локальные уведомления (expo-notifications).
  - `src/state/store.tsx` — данные в AsyncStorage, после изменений перепланирует уведомления.
  - `src/ui/` — общие компоненты и цвета (`kit.tsx`).
- `.github/workflows/android-apk.yml` — собирает APK и публикует его в релиз `apk`.
- `.github/workflows/iphone-expo-go.yml` — публикует обновление EAS Update для Expo Go (канал `preview`) и ссылку в релиз `iphone`. SDK приложения должен совпадать с SDK текущего Expo Go в App Store.

## Команды

```bash
cd app && npm test && npm run typecheck
```

Перед изменениями в приложении: Expo часто меняет API — сверяйтесь с типами в `node_modules`, а не с памятью. Пакеты ставьте через `npx expo install`.

## Правила

- Приложение должно оставаться простым: брат пользуется им без инструкций.
- Данные о людях хранятся только на телефоне.
- Каждое изменение логики дат или напоминаний — с тестом.
